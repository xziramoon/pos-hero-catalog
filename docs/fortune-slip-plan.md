# แผนอัปเกรด POS Hero: พิมพ์เซียมซีต่อท้ายใบเสร็จ Sea & Hill

> อัปเดต 6 พ.ย. 2569 (ฉบับ 3) · ไฟล์แนบ: `fort.js` (ข้อมูลเซียมซี 100 ใบ), `เซียมซี-100-ใบ.md` (ฉบับตรวจทานคำแปล)

## เปลี่ยนจากฉบับก่อน
- เพิ่ม **กลอนแปลไทย** 4 บรรทัดทุกใบ ใช้คำง่าย อ่านเข้าใจทันที
- เพิ่มสวิตช์ **ใส่กลอนจีน** และ **ใส่กลอนแปลไทย** เปิด/ปิดแยกกันได้
- สวิตช์ใบ 下签 เปลี่ยนเป็น **ปิดใบโชคร้าย** ค่าเริ่มต้น = เปิด (ไม่สุ่มใบโชคร้าย)
- `fort.js` เพิ่มช่องที่ 5 = กลอนแปลไทย

## สรุปสั้น
- **ทุกบิล** ที่ Sea & Hill พิมพ์ จะมีใบเซียมซีเจ้าแม่กวนอิมต่อท้าย **บนกระดาษแถบเดียวกัน** แล้วจึงตัด ไม่มีเงื่อนไขยอดเงิน
- ใช้ **วิธีที่ 1** (ทดสอบที่หน้าร้านแล้วว่าใช้ได้): ตั้งไดรเวอร์ TM-T82III เป็น Paper Cut = No Cut → POS Hero พิมพ์เซียมซีต่อ แล้วส่งคำสั่งตัดเอง
- **อัปเกรด POS Hero** ไม่สร้างแอปใหม่ เขียนเป็นโมดูลแยกในโฟลเดอร์ `fortune/`
- ข้อมูลเซียมซีใช้ **觀音靈籤 100 ใบของจริง** ชุดเดียวกับหน้าวงล้อลุ้นโชค

## การตัดสินใจที่ได้ข้อสรุปแล้ว
| เรื่อง | ข้อสรุป |
|---|---|
| ใครได้เซียมซี | ทุกบิล |
| วิธีต่อท้าย | ไดรเวอร์ไม่ตัด + POS Hero พิมพ์ต่อแล้วตัด (วิธีที่ 1) |
| ที่อยู่ของโค้ด | POS Hero เวอร์ชันถัดไป (โมดูล `fortune/`) |
| ชุดเซียมซี | เจ้าแม่กวนอิม 100 ใบ: 上签 23 / 中签 60 / 下签 17 |
| ใบโชคร้าย (下签 17 ใบ) | สวิตช์ **ปิดใบโชคร้าย** ค่าเริ่มต้นเปิด → สุ่มจาก 83 ใบ |
| กลอนจีน | สวิตช์เปิด/ปิด ค่าเริ่มต้นเปิด |
| กลอนแปลไทย | สวิตช์เปิด/ปิด ค่าเริ่มต้นเปิด |
| ช่วงเวลาใช้งาน | กำหนดวันเริ่ม/วันจบได้ พ้นช่วงแล้วเหลือแค่คำสั่งตัดกระดาษ |

## ทำไมอัปเกรด POS Hero แทนการสร้างแอปใหม่
| | อัปเกรด POS Hero | สร้างแอปใหม่ |
|---|---|---|
| ระบบพิมพ์ raw ESC/POS เข้า TM-T82III | มีแล้ว (`buildEscPosRaster`, `build/raw-print.ps1`) | ต้องเขียนซ้ำ |
| เปิดเองตอนเปิดเครื่อง + ไอคอนถาด | มีแล้ว (`openAtLogin`, Tray) | ต้องทำใหม่ |
| โปรแกรมที่พนักงานต้องดูแล | เท่าเดิม | เพิ่ม 1 ตัว |
| ความเสี่ยง | บั๊กเซียมซีอาจกระทบ POS Hero | แยกขาดกัน |

ลดความเสี่ยงด้วย: โมดูลแยกไฟล์, สวิตช์เปิด/ปิด, try/catch ครอบทุกจุด, ไม่แตะโค้ดกระทบยอดและลิ้นชักเงิน

## หน้าตาใบเซียมซี (ต่อจากใบเสร็จ)
```
- - - - - - - - - - - - - - - - - -
      เซียมซีเจ้าแม่กวนอิม
     ใบที่ 61 · 中签 · กลาง
          啸聚山林凶恶俦          ← สวิตช์ "กลอนจีน"
          善良无事苦煎忧
          主人大笑出门去
          不用干戈盗贼休
   คนร้ายรวมตัวกันในป่าเขา        ← สวิตช์ "กลอนแปลไทย"
   คนดีไม่ได้ทำอะไรแต่กลุ้มใจ
   เจ้าบ้านหัวเราะเดินออกไป
   ไม่ต้องสู้ โจรก็เลิกไปเอง
ความหมาย: แม้มีคนร้ายรวมตัว แต่คนดี
ไม่เป็นอะไร เรื่องร้ายสงบได้โดยไม่ต้องสู้
การเงิน: ราบรื่น
  สวัสดีปีใหม่ 2570 · อึ้งลักเส็ง 黄六盛
```
- กว้าง 576 px (80 มม.) ขาวดำล้วน ยาวประมาณ 6–7 ซม. ถ้าเปิดทั้งสองกลอน, ประมาณ 4 ซม. ถ้าปิดทั้งสอง
- ต้องเรนเดอร์ใหม่ทุกครั้งที่เปลี่ยนสวิตช์กลอน (ภาพที่แคชไว้ขึ้นกับค่าสวิตช์)
- กลอนจีนวรรคละบรรทัด ใช้ฟอนต์ที่มีอักษรจีน (Microsoft YaHei / SimSun บน Windows)
- ภาษาไทยใช้ Sarabun ตัวหนา ขนาด ≥ 22 px เพื่อให้ชัดหลังแปลงขาวดำ

## ข้อมูลเซียมซี (`fort.js`)
- รูปแบบ: `[ระดับ, "กลอนจีน วรรค1，วรรค2\nวรรค3，วรรค4", "ความหมายไทย", "การเงิน", "กลอนแปลไทย 4 บรรทัดคั่นด้วย \n"]` × 100 ใบ (index 0 = ใบที่ 1)
- ป้ายระดับ: `上` → 上签 · ดี, `中` → 中签 · กลาง, `下` → 下签 · รอจังหวะ (ใบโชคร้าย)
- ที่มา: กลอนและระดับจากชุดข้อมูล 觀音靈籤 ในแพ็กเกจ `qiantong` (MIT) ตรวจเทียบใบที่ 100 กับ masterseanchan.com ตรงกัน
- กลอนแปลไทยและความหมายแปลใหม่ด้วยคำง่าย ไม่ได้ลอกคำแปลของวัด/ศาลเจ้าใด **ควรให้คนอ่านจีนออกตรวจก่อนใช้จริง** (ใช้ไฟล์ `เซียมซี-100-ใบ.md` ซึ่งวางจีนคู่ไทยบรรทัดต่อบรรทัด)

## โครงสร้างไฟล์ใหม่ใน POS Hero
```
fortune/
  fortunes.json      แปลงจาก fort.js
  slip.html          หน้าตาใบเซียมซี กว้าง 576px
  slip-renderer.js   เรนเดอร์ 100 ใบในหน้าต่างซ่อน → ESC/POS เก็บไว้ในหน่วยความจำ
  job-watcher.ps1    PowerShell รันค้าง 1 ตัว เฝ้าคิวเครื่องพิมพ์ ส่ง JSON ออก stdout
  fortune-main.js    รับเหตุการณ์ → สุ่มใบ → พิมพ์ → สำรองตัดกระดาษ
```
แก้ไฟล์เดิมเล็กน้อย: `main.js` (require + ipc), `preload.js` (API ตั้งค่า), `package.json` (`files` + `asarUnpack` สำหรับ .ps1)

## ขั้นตอนการทำ

### ขั้น 0 — เก็บข้อมูลงานพิมพ์ (ครึ่งวัน)
- `job-watcher.ps1` โหมดบันทึกอย่างเดียว: ทุก 300 ms อ่าน `Get-PrintJob` ของ TM-T82III พิมพ์ JSON (id, ชื่อเอกสาร, สถานะ, เวลา) เมื่อมีงานเข้า/ออกจากคิว
- ขายจริง 3–5 บิล + พิมพ์ซ้ำ 1 ใบ + ปิดกะ 1 ครั้ง
- ได้: ชื่อเอกสารใบเสร็จ Sea & Hill เทียบกับงานอื่น และเวลาตั้งแต่เข้าคิวจนพิมพ์จบ

### ขั้น 1 — ใบเซียมซี + ปุ่มทดลองพิมพ์ (1 วัน)
- ทำ `slip.html` ตามแบบด้านบน
- ตอนเปิดโปรแกรม เรนเดอร์ทั้ง 100 ใบในหน้าต่างซ่อน (`show:false`, กว้าง 576px) → `capturePage` → แปลงเป็น ESC/POS แล้วเก็บ Buffer ไว้ พิมพ์จริงจะไม่มีความหน่วง
- แยก `buildEscPosRaster` ให้เลือกได้ว่าจะใส่ `ESC @` และคำสั่งตัดหรือไม่ **ใบเสร็จเดิมของ POS Hero ต้องได้ไบต์เหมือนเดิมทุกไบต์**
- ปุ่ม "ทดลองพิมพ์เซียมซี" ในหน้าตั้งค่า

### ขั้น 2 — ต่อท้ายอัตโนมัติ (1 วัน)
- watcher รันค้างเป็น child process ตัวเดียว รีสตาร์ทเองถ้าตาย
- งานที่ชื่อตรงกับใบเสร็จ Sea & Hill **พิมพ์จบ** → ส่งเซียมซี + `ESC d 2` + `GS V 65 0`
- งานอื่นที่จบ (รายงานปิดกะ, Chrome ฯลฯ) → ส่งคำสั่งตัดอย่างเดียว เพราะไดรเวอร์ไม่ตัดให้แล้ว
- ข้ามงานของ POS Hero เอง (ชื่อ "POS Hero Receipt")
- กันซ้ำ: จำ job id ที่จัดการแล้ว 200 รายการล่าสุด
- **สำรองตัดกระดาษ:** พิมพ์เซียมซีพลาด / ปิดสวิตช์ / พ้นช่วงวันที่ → ส่งแค่คำสั่งตัด ใบเสร็จต้องถูกตัดเสมอ
- สุ่มใบด้วย `crypto.randomInt` จากชุดที่อนุญาต (ปิดใบโชคร้าย = ตัด 下签 ออก)

### ขั้น 3 — ตั้งค่าและสถิติ (ครึ่งวัน)
- ตั้งค่า: เปิด/ปิดเซียมซี, **ปิดใบโชคร้าย**, **ใส่กลอนจีน**, **ใส่กลอนแปลไทย**, ชื่อเครื่องพิมพ์, ตัวกรองชื่อเอกสาร, วันเริ่ม–วันจบ, ปุ่มทดลองพิมพ์
- เปลี่ยนสวิตช์กลอน → เรนเดอร์และแคชใบเซียมซีใหม่ทันที
- นับจำนวนใบที่พิมพ์วันนี้ แสดงในเมนูถาด
- แจ้งเตือนถ้า watcher หยุดทำงานเกิน 30 วินาที

### ขั้น 4 — ทดสอบและใช้จริง
- ทดสอบที่สาขาเดียว 2–3 วัน: ขายปกติ, พิมพ์ซ้ำ, ปิดกะ, เปิดลิ้นชัก, ถอดสาย USB ระหว่างพิมพ์, ปิด POS Hero ทิ้งไว้
- จดปริมาณกระดาษที่ใช้เพิ่มต่อวัน
- ติดตั้งสาขาที่สอง

## ความเสี่ยงและทางแก้
| ความเสี่ยง | ทางแก้ |
|---|---|
| POS Hero ปิด/ค้าง → ใบเสร็จไม่ถูกตัด | เปิดเองตอนเปิดเครื่องอยู่แล้ว + แจ้งเตือน + ติดวิธีตั้ง Paper Cut = Cut กลับไว้ที่เคาน์เตอร์ |
| โปรแกรมอื่นที่พิมพ์ผ่านไดรเวอร์นี้ไม่ตัด | ส่งคำสั่งตัดให้ทุกงานที่จบ |
| มีงานอื่นแทรกระหว่างใบเสร็จกับเซียมซี | ส่งเซียมซีทันทีที่งานจบ ช่องว่างสั้นมาก |
| ตัวอักษรไทย/จีนไม่ชัดหลังแปลงขาวดำ | ฟอนต์หนา ขนาดใหญ่ + ทดสอบค่า threshold |
| แก้ `buildEscPosRaster` แล้วใบเสร็จเดิมเพี้ยน | เทียบไบต์ก่อน/หลังด้วยภาพตัวอย่างเดียวกัน |
| ลูกค้าไม่สบายใจกับใบโชคร้ายช่วงปีใหม่ | สวิตช์ปิดใบโชคร้าย (เปิดไว้เป็นค่าเริ่มต้น) |
| ใบยาว เปลืองกระดาษ | ปิดกลอนจีนหรือกลอนไทยอย่างใดอย่างหนึ่ง |

## ข้อมูลที่ยังต้องได้จากหน้าร้าน
1. ชื่อเครื่องพิมพ์ใน Windows ของแต่ละสาขา
2. ทั้งสองสาขามี POS Hero ติดตั้งอยู่หรือยัง
3. ผลจากขั้น 0 (ชื่อเอกสารใบเสร็จของ Sea & Hill)
4. ช่วงวันที่ใช้งาน และจะเปิดกลอนแบบไหน (จีน / ไทย / ทั้งสอง)
