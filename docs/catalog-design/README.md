# ไฟล์ดีไซน์ (อ้างอิง)

ไฟล์ `canvas/*.dc.html` มาจากแคนวาสดีไซน์บน claude.ai ใช้**อ่านอ้างอิง** โครงหน้า สี ขนาด และพฤติกรรมตอนคลิก ไม่ได้เอาไปรันตรงๆ
(ต้องใช้ runtime ของแคนวาส และรูปอ้างอิงเป็นลิงก์ `/_blob/...` ที่เปิดได้เฉพาะในแคนวาส) ถ้าอยากกดเล่นจริง ให้เปิดลิงก์แคนวาสใน `_PRIVATE_do_not_commit/links.md`

| ไฟล์ | หน้า |
|---|---|
| `Main.dc.html` | **กระเป๋าสินค้า (แบบที่ใช้)** — ชุดเดียวกับ POS Hero, 4 ธีม, คลิกช่องเพื่อคัดลอก, ปุ่มกระเป๋าข้าง mini widget |
| `Crop.dc.html` | หน้าปรับรูป — 2 กรอบ (ช่องตาราง/การ์ด), ลาก, ซูม, หมุน |
| `PhotoTest.dc.html` | ทดสอบรูป 8 เคส × 3 วิธีแสดงผล |
| `Main-v1.dc.html` | แบบแรก (เลิกใช้แล้ว เก็บไว้ดูเฉยๆ) |

ค่าสีและขนาดที่ใช้จริงให้ยึดตามสเปกหัวข้อ 7 และภาคผนวก B ไม่ใช่ตามไฟล์เหล่านี้
